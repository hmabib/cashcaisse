Guide
Simple English guide for roles, process, and daily steps.

Roles

Ordonnateur: validates the expense and gives final approval.

Controleur: checks compliance, supporting documents, and budget rules.

Regisseur: records replenishment, payment, and cash movement.

User account rule: the login is the email. The default password is the lowercase first name.

Default Accounts

User IDs follow the format prenom.nom@pak.cm.

Passwords are managed in the backend and are not shown in the interface.

These accounts are seeded automatically in the database schema caisse.

Daily Process

Step 1: login to the platform.

Step 2: create or update suppliers.

Step 3: create the invoice and let the app calculate the net payable amount.

Step 4: verify the invoice checklist and approve or reject it.

Step 5: record the disbursement only after approval.

Step 6: review accounting, audit, and official documents.

Data Process

The app sends each change to the backend API.

The API stores data in PostgreSQL on Heroku.

The PostgreSQL objects are inside the schema caisse.

Vercel hosts the frontend and the serverless API.

Delete In Case of Doubt

You can delete accounting entries from the journal if an entry is doubtful.

After deletion, the running balance is recalculated automatically.

Use this only when the team has confirmed the correction.
